# API Documentation

The REST API is built with FastAPI and lives in the `api/` directory.

## Endpoints

- `GET /health` – Health check
- `POST /api/v1/training` – Start a training job
- `POST /api/v1/prediction` – Make predictions
- `GET /api/v1/models` – List trained models
- `GET /api/v1/datasets` – List available datasets
- `GET /api/v1/reports` – Get evaluation reports
